  FOUR THINGS TO KNOW FIRST:

    1. You need an AMD Radeon RX 7000 or RX 9000 card. On NVIDIA it is
       pointless (they already have DLSS) and on older cards it will not work.

    2. This mod does NOT raise your fps: it LOWERS them. It changes how the
       image looks, not how fast it runs.

    3. It works with Football Life 2026 (tested) and with PES 2021 from Steam,
       with or without sider (same game and engine, but not tested).

    4. OFFLINE ONLY. Before myClub or online play run
       DISINSTALLA - UNINSTALL.bat. Switching the effect off is not enough.

  HOW TO INSTALL (internet needed, about 10 minutes):

       1. Close the game (and sider, if you use it).

       2. Double-click:     INSTALLA - INSTALL.bat
          Windows asks for administrator rights: answer Yes.
          If the blue SmartScreen warning appears: "More info"
          -> "Run anyway".

       3. In the window press INSTALL. Pick ITA or ENG at the top right.

       4. It asks "I found the game here: ... Install into this folder?".
          Answer Yes. If it cannot find it, it lets you pick the
          FL_2026.exe (Football Life) or PES2021.exe (PES 2021) yourself.
          Do NOT rename the game executable: there is no need.

       5. It downloads the add-on by itself. Then Daniel Blanco's official
          installer opens (his licence asks to go through it): pick a
          language, run the machine check, download the files (about
          165 MB) and CLOSE IT. The installer does the rest.

       6. If needed, the ReShade setup opens: pick Direct3D 10/11/12 and no
          effects. Usually it is not needed, because ReShade already comes
          with Blanco's files.

       7. Wait for DONE!  Then start the game as usual.
          In game: HOME opens the panel, CTRL+END switches the effect on.

  If everything is already installed, the installer says so and touches
  nothing.

  TO UPDATE: just run   INSTALLA - INSTALL.bat   again. It checks online which
  versions I have tested and, if you are behind, updates you while keeping your
  settings (each replaced file is kept as a .precedente.bak copy).

  TO REMOVE EVERYTHING:   DISINSTALLA - UNINSTALL.bat
  Note: it also removes your settings (dlss5-neural.ini and ReShade.ini).
  The game's original files are never touched.
